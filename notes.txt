Set up

PlatformIO - https://platformio.org/

Install pio on mac:
  brew install platformio

Set up project:
  pio project init --board uno
  pio run -t compiledb

Run project:
  pio run
  pio run --target upload

Get the device list and usb port
  pio device list
  * find the usb port of the board and add "upload_port = /dev/port-name" to ini file

Set up lazyvim for c++:
  Install with mason: clangd (c++)
